# E-Commerce Web Application

This is a web application built with C# and ASP.NET MVC. It lets users browse products, add them to a cart, and write reviews. There is also an admin panel to manage products and users.

---

## Features

- Browse products by category  
- View product details  
- Add products to shopping cart  
- User registration and login  
- Write and manage product reviews  

Admin panel:  
- Manage products, categories, and users  
- Approve or delete reviews  

---

## Technologies

- C#  
- ASP.NET MVC  
- SQL Server  

---

## How to Run

1. Open the solution in Visual Studio  
2. Set up the database (backup or script in /Database folder)  
3. Update the connection string in `web.config`  
4. Run the project
